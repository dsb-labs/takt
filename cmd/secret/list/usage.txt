List the secrets the server holds, with the workloads reading each one.

No value is reported, here or anywhere else. This is how you find out what
exists in order to reference it from a manifest.

Repeat --query to narrow the result. A secret has to match all of them.
A query is a JSON path into the secret's labels and the value it must
hold:

  takt secret list --query '$.labels.app=web'
  takt secret list -q '$.labels.app=web' -q '$.labels.env=prod'
